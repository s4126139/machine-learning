# Introduction to Neural Networks

Source: Canvas module item 8460509

## Topics

This module introduces Artificial Neural Networks, beginning with the Perceptron and
then moving to Multilayer Perceptrons (MLPs). It covers weights, activation
functions, learning rules, forward propagation, backpropagation, gradient descent,
learning rates, overfitting, regularisation, architecture choices, initialisation,
and optimisation.

## Outcomes

By the end of the module, students should be able to:

- build and train basic MLP neural networks;
- explain the mathematical ideas behind forward and backward propagation; and
- apply neural networks to real problems and evaluate their performance.

The page also notes that these foundations support the later Deep Learning module and
Assignment 2.
