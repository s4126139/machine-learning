# Week 6 Applications — ANN and MLP

Source: Canvas module item 8460515

## Main ideas

Artificial Neural Networks and Multilayer Perceptrons can learn complex patterns for
classification, regression, and function approximation.

The page focuses on four useful strengths:

- **Forecasting:** ANNs are data-driven and self-adaptive, so they can model complex
  relationships when the underlying process is not fully known.
- **Generalisation:** a trained ANN can apply patterns learned from historical data to
  unseen inputs, which is important in time-series prediction and demand forecasting.
- **Universal approximation:** with sufficient data and a suitable architecture,
  neural networks can approximate continuous functions to an arbitrary accuracy.
- **Nonlinearity:** ANNs can learn nonlinear relationships without requiring the
  modeler to specify a fixed functional form in advance.

The original page includes references to work on universal approximation and
nonlinear forecasting; the citations remain available through the Canvas source.
