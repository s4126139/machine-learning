# Week 9 Lab — Deep Learning (CNN)

Source: Canvas module item [8460549](https://rmit.instructure.com/courses/171525/modules/items/8460549)

Captured: 2026-09-24

## Lab goals

- Use the Keras API in TensorFlow.
- Build a basic CNN for image classification with the CIFAR-10 dataset.
- Work with a 10,000-image subset of CIFAR-10.
- Practise EDA, train/validation/test preparation, model construction, and learning-
  curve diagnosis.
