# Introduction to Unsupervised Learning

Source: Canvas module item [8460542](https://rmit.instructure.com/courses/171525/modules/items/8460542)

## Overview

Unsupervised learning works with data without explicit labels. Instead of being told
what to predict, the algorithm discovers hidden structures, patterns, or groupings in
the data.

This module introduces two core methods:

- **K-Means clustering** partitions data into non-overlapping groups based on feature
  similarity. The algorithm repeatedly assigns points to clusters and updates cluster
  centres to reduce within-cluster variation.
- **Hierarchical clustering** builds a tree-like dendrogram that represents data
  relationships at different levels of granularity. The module covers agglomerative
  (bottom-up) and divisive (top-down) approaches.

## Applications

The page highlights customer segmentation, anomaly detection, and data summarisation
as examples of real-world uses.

## Learning objectives

The module contributes to understanding machine-learning concepts and algorithms,
setting up data-processing and feature-engineering workflows, applying machine-
learning toolkits, and understanding major application areas.

Clustering is a foundational part of machine learning. Later classes can use or build
on these ideas.
