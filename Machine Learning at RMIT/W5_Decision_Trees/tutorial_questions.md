# Week 5 Tutorial Questions — Decision Trees

Source: Canvas W5 Tutorial Questions

Captured: 2026-09-24

The tutorial revises decision trees and Random Forests, with exercises on:

- constructing a univariable tree for a two-class problem;
- evaluating a tree and choosing a useful split for a mixed leaf; and
- calculating information gain and gain ratio for attributes in the Sailing dataset.

The Canvas page names entropy, information gain, pruning, and gain ratio as the concepts to review.
