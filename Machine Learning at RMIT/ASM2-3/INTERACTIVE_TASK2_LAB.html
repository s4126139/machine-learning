      What to remember

        What is convolution?

        A small filter slides across an image to find patterns such as edges, colour, or sleeves. It creates feature maps.

        What is an embedding?

        A numerical “summary” of an image. C1 has 256 numbers; ResNet18 has 512.

        What is a logit?

        It is one of 4 raw scores. Softmax turns them into probabilities. The largest logit is chosen.

        What does I2 actually receive at inference?

        1. 1Read one new image, check its size, and turn it into a tensor.
        2. 2SmallCNN makes a 256-number embedding and Season logits [N, 4].
        3. 3Divide logits by T = 1.3650016, then use softmax to get probabilities.
        4. 4Choose the label with the largest probability: Fall / Spring / Summer / Winter.

        Golden rule

        I2 uses ArticleType as an extra label during training. When predicting, predict_season_logits(images) receives only an image. Do not give the model true ArticleType, year, or metadata.

        After submission · a separate research trail

        What did we try after freezing I2?

        The original G0–G9 story ends with the submitted, scratch-trained I2. The experiments below ask new questions; they do not become G10, change the 20 original development configurations, or replace the submitted model.

        Keep the evidence boundary clear: development out-of-fold (OOF) comparisons use 32,753 labelled images. The later 5,778-image internal-holdout comparison is retrospective: that holdout had already been opened for the submitted I2. It is useful evidence, but not a fresh, untouched test for choosing a new submission.
        1 · Did ReLU kill whole channels? Audit before changing the activation.

        Question. ReLU turns negative values into zero. Does that mean some complete feature channels in I2 can no longer respond?

        Method. Examine the frozen I2 over each complete validation fold. A channel is exact-dead if its largest absolute output is at most 10−12 across that fold. It is near-dead if its input to ReLU is positive less than 1% of the time.

        Result. Across five folds and 4,800 channel–fold observations, there were zero exact-dead and zero near-dead channels. About 56.64% of individual activation values were zero. That is ordinary sparsity, not “56.64% dead neurons.”

        Decision. A LeakyReLU swap was not justified as a dead-channel fix. Two early LeakyReLU folds completed, one run failed, and one was interrupted; that is not a five-fold model comparison, so it cannot establish whether LeakyReLU is better or worse. See the activation definitions and counts (source file not bundled with this page), attempt statuses (source file not bundled with this page), and experiment code (source file not bundled with this page).

        2 · Can a tree model use I2's learned image features better?

        Hypothesis. Keep the CNN's learned visual features, but change the final decision rule. A Random Forest (RF) or histogram gradient boosting (HGB) might separate the four seasons better than I2's own linear Season head.

        Image→ Frozen fold-specific I2→ 256-number embedding→ RF or HGB head→ Four Season probabilities

        For each fold, the tree head learned only from that fold's training images; its validation images were used only for prediction. ArticleType was an auxiliary label during I2 training, not an input to the tree head. The RF used 300 trees, Gini splits, two or more samples per leaf, and square-root feature sampling.

        3 · Refit only the RF head; what happened on the already-opened holdout?

        What was fitted? The full-development I2 encoder weights stayed frozen. We extracted a 256-number embedding for each of the 32,753 development images and fitted one new 300-tree RF head. No holdout image or label entered that fit. This is not retraining the CNN from scratch.

        Retrospective comparison. Both models predicted the same 5,778 internal-holdout images. The holdout had already been used to audit the original I2, so this improvement is exploratory rather than fresh independent proof of a new winner.

        Retrospective internal-holdout results on 5,778 images
        Internal holdoutSubmitted I2I2 embedding + RF
        Macro-F10.753380.76567
        Accuracy0.764280.77310

        The paired macro-F1 gain was +0.01228. Resampling complete product families 10,000 times gave a descriptive 95% interval of [+0.00625, +0.01864]. The interval is positive, but it does not restore the holdout's original independence.

        Trade-offs. RF probabilities were not temperature-calibrated like I2, and their log-loss was worse. The combined model files were about 51.2 MB versus 4.9 MB for I2. Recorded CPU throughput was about 126 versus 462 images/s in separate runs, so treat the speed ratio as indicative, not a matched benchmark. Both models nearly lost Spring under brightness 0.85: Spring recall was about 0.0043. The RF is a heavier exploratory alternative, not a safe automatic replacement.

        Artifacts. The RF needs the original I2 .pt plus a separate .joblib head and matching manifest. No official teacher-test export was made.         4 · Could a small RF-head grid beat the first RF?

        Controlled change. Keep I2, the five folds, 300 trees, and seeds fixed. Change only min_samples_leaf (1, 2, or 4) and max_features (square root or 0.25 of 256). The reference is the RF above: leaf 2 + square root. The grid has five recipes × five folds = 25 recorded runs.

        Rule set in advance. A new RF head needed at least +0.003 pooled OOF macro-F1, no Spring F1 fall greater than 0.005, and a family-bootstrap interval whose lower end was above zero. Holdout labels were not used to choose the grid result.

        Check yourself before moving on

        If 56.64% of ReLU values were zero, why did we not call 56.64% of channels dead?

        A zero value is one output for one image/location. A dead channel would fail to respond across the complete validation fold. None met that definition.

        Why is the positive RF holdout interval not proof of a new submission winner?

        The holdout was already opened for I2 before this research. The paired interval describes the observed gain; it does not make the reused holdout a fresh independent selection set.

        Why keep r0 when some grid recipes improved Spring F1?

        The predeclared gate required an overall macro-F1 gain too. All alternatives scored below r0 overall, and their paired intervals included zero.
