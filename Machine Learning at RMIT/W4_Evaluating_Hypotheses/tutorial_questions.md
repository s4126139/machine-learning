# Week 4 Tutorial Questions — Evaluation

Source: Canvas [W4 Tutorial Questions](https://rmit.instructure.com/courses/171525/modules/items/8460488)

Captured: 2026-09-24

The tutorial asks students to:

1. Calculate MAE, MSE, and RMSE from a small regression test set.
2. Build a confusion matrix and calculate accuracy, precision, recall, and F1 score.
3. Explain k-fold cross-validation and why it is used.
4. Explain the Lasso loss and how the regularisation parameter affects model complexity.

The Canvas page objectives also mention evaluation metrics, regularisation, and the bias–variance trade-off.
