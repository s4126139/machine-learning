# Introduction to Practical Issues of Machine Learning

Source: Canvas module item [8460557](https://rmit.instructure.com/courses/171525/modules/items/8460557)

## Overview

Real-world machine-learning work involves more than choosing an algorithm and
training it. This module focuses on the practical decisions that affect model
performance, interpretability, and robustness.

## Topics

- **Feature selection** identifies relevant input variables to reduce dimensionality,
  improve generalisation, and reduce overfitting.
- **Feature construction** transforms raw data into useful input features.
- **Principal Component Analysis (PCA) and kernel methods** reduce dimensionality or
  represent nonlinear structure while preserving important information.
- **Ensemble learning** combines models using methods such as bagging and boosting
  to improve accuracy, stability, and resilience to noise.

The module aims to help students design, evaluate, and optimise machine-learning
pipelines for high-dimensional, noisy, or complex data.
