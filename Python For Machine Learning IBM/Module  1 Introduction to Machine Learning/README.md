# Module 1: Introduction to Machine Learning

These notes consolidate all 12 entries in the Notion database **Module 1 Introduction to Machine Learning** into a practical English study guide. Repeated material has been merged, while distinct examples, comparisons, tools, workflows, and assessment points have been preserved.

## Learning outcomes

After studying this module, you should be able to:

- Explain the relationship among artificial intelligence, machine learning, and deep learning.
- Distinguish supervised, unsupervised, semi-supervised, and reinforcement learning.
- Match common problems to classification, regression, clustering, anomaly detection, association, sequence mining, dimensionality reduction, or recommendation systems.
- Describe the machine learning lifecycle from problem definition through monitoring and retraining.
- Explain why data collection and preparation usually consume a large share of project effort.
- Compare the typical work of data scientists, machine learning engineers, and AI engineers.
- Map languages, libraries, frameworks, and platforms to their roles in an ML system.
- Describe and implement a basic Scikit-learn workflow.
- Explain how a trained model becomes a production service at a high level.

## Module at a glance

```text
Business or user problem
        ↓
Relevant, representative data
        ↓
Preparation and feature engineering
        ↓
Model training and validation
        ↓
Deployment into an application
        ↓
Monitoring, feedback, and retraining
        ↺
```

The central idea is that machine learning is not merely an algorithm. It is an iterative system of problem framing, data work, modeling, evaluation, deployment, and continuous improvement.
